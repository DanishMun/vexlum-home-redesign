# Vexlum home page – concept redesign

A one-page concept for a new Vexlum (vexlum.com) home page, built by Danish Munawar.
This is not the official Vexlum website. Text and images come from vexlum.com.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Files

- `app/page.js` – the home page, section by section
- `app/Header.js` – top menu (opens and closes on phones)
- `app/data.js` – all the text: stats, products, news
- `app/globals.css` – all the styles, with Vexlum's colours at the top
- `public/images` – photos from vexlum.com, made smaller for speed

## What changed compared with the current site

1. Clear headline that says who the lasers are for (quantum, space, chip-making).
2. Key numbers right under the hero (wavelength range, power, linewidth, made in-house).
3. Products shown as two cards (VALO for research, VXL for enterprise) with datasheet links.
4. "How it's made" in three simple steps.
5. Latest news on the home page, so the site feels active.
6. New careers section, for a company that is growing fast.
7. The empty "Contact us" block now has real actions: request a quote, email sales.
8. Works well on phones.
